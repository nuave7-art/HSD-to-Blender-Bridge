-Export a clean model without anims from HSDRaw

-Export an anim file from HSDRaw

-Import your .dae model

-Select your model armature

-Use https://github.com/PositionWizard/Blender_io-scene-ANIM to import .anim files into Blender 3.6

-Go into the script tab in blender, open this HSD-to-Blender Bridge script

-Modify the lines that say .dae path and .anim path to the folder paths

-Press run, it should perfectly convert the changes so you now have a playable anim in Blender
